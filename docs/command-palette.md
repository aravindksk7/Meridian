# Command palette

Open the palette with `Ctrl+K` on Windows/Linux or `Cmd+K` on macOS. Search covers:

- templates;
- nodes in the current diagram;
- SVG, PNG, and GIF export;
- preview navigation and fullscreen presentation;
- Layers, Component Properties, Design Tokens, and settings.

Use Up/Down to navigate, Enter to run, and Escape to close without executing.
