# Multi-select and alignment

- Shift-click nodes on the canvas or in Layers to add or remove them from the selection.
- The selection toolbar supports bulk color, duplicate, lock, grid alignment, delete, and component-property edits.
- Arrange supports left, center, right, top, middle, bottom, horizontal distribution, and vertical distribution.
- Grouping stores lightweight editor membership. Selecting one grouped node restores the full grouped selection without rewriting Smart Input or creating a Mermaid subgraph.

Manual arrangement changes use Meridian's existing diagram-scoped position persistence.
