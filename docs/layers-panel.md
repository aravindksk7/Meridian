# Layers panel

The Layers panel presents the parsed diagram as a searchable hierarchy:

- domains, environments, network zones, and subdomains;
- nested and ungrouped nodes;
- relationships with labels;
- canvas annotations.

Selecting a node layer selects and centers its canvas node. Group and relationship rows navigate to Smart Input. Disclosure state is stored separately from diagram group-collapse state, so organizing the Layers panel never changes the rendered diagram.
