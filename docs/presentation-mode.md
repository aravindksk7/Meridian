# Presentation mode

Presentation mode hides the application header, Smart Input, editor panels, status bar, and preview toolbar. The diagram is fitted and centered in the full canvas.

The floating presentation toolbar supports:

- named saved views containing zoom, scroll position, and selected nodes;
- previous/next view navigation with buttons or Left/Right arrows;
- deletion of the current saved view;
- fullscreen preview;
- Exit or Escape to return to editing.

Saved views persist locally without changing Smart Input or exported Mermaid source.
