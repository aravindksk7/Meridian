Quick Start
Type shorthand in the Smart Input panel — the diagram updates live. No special knowledge of Mermaid.js required.
Basic example
// Group services in a deployment environment env:Production { app:WebServer db:PostgreSQL instance:Redis_Cache } // Connect with arrows — A --label--> B app:WebServer --SQL--> db:PostgreSQL app:WebServer --session--> instance:Redis_Cache
Mark business ownership
// domain: colours nodes without changing their position domain:Platform { app:WebServer instance:Redis_Cache } // WebServer and Redis_Cache stay inside env:Production // but are tinted with Platform's colour
Tips
  • Use underscores for spaces: app:My_Service
  • Comments: lines starting with // or # are ignored
  • Multi-line blocks: open with env:Name { and close with } on its own line
  • Switch views with the Diagram type dropdown — Flowchart, Design Board, Sequence, Class
  • Use 🏷️ Entities ▾ to pick an entity type — it inserts the prefix and you just type the name
  • Use 📋 Templates ▾ to load a working example instantly
  • Use ☁️ Icons ▾ to browse 1,274 service icons across AWS, GCP, Azure, General, and AI tabs — click any icon to insert it with its emoji embedded in the label
  • Use the 🤖 AI icon tab for AI stack diagrams — LLMs, frameworks, vector DBs, MLOps, and more. Pair with the 🤖 AI / RAG App template to start quickly
  • Click the zoom percentage (e.g. 100%) in the preview toolbar to open a zoom preset picker — from 25% to 500%

Arrows & Relationships
Connect any two entities with arrow syntax. Labels go between the dashes.
SyntaxArrow typeBest for
A --> B→ NormalBasic flow or dependency
A --label--> B→ LabelledNamed relationship e.g. --HTTPS-->
A <--> B↔ BidirectionalTwo-way communication
A --pre--> B- - → DashedPrerequisite / must run before
A --requires--> B- - → DashedSame as --pre-->
A --post--> B═══▶ ThickTriggers on completion
A --triggers--> B═══▶ ThickSame as --post-->
batch:A >> batch:B >> batch:C═══▶ ChainSequential batch pipeline
Pre / post label keywords (auto-select style)

Dashed (prerequisite): pre pre- prerequisite requires before

Thick (on-completion): post post- triggers then after

Example
// Batch pipeline batch:Extract >> batch:Transform >> batch:Load // Pre/post dependencies batch:Extract --pre--> db:StagingDB batch:Load --post--> app:NotificationService // Bidirectional app:Frontend <--> app:Backend
Grouping Blocks
Four block types create colorful visual subgraphs. They can be mixed freely on the same diagram, and the live preview can collapse or expand them without editing Smart Input.
BlockPurposeVisual
env:Name { … } Deployment environment
Production, Staging, Dev…		 Solid 2px blue border
net:External { … } External / internet-facing zone Solid red border
net:DMZ { … } Demilitarised zone Solid orange border
net:Internal { … } Private / internal zone Solid blue border
domain:BU { … } Business domain / team ownership boundary Dashed 3px coloured border
auto-colour per domain
subdomain:Capability { … } Nested capability group inside a domain Indented dashed border
inherits the parent domain palette
Live collapse controls

Rendered env:, net:, domain:, and subdomain: groups include a small Collapse control. Collapsing replaces the group with a styled proxy node, redirects incoming and outgoing edges to that proxy, and persists the state in localStorage. Click Expand on the proxy to restore the full group.

Multi-line block syntax
env:Production { app:WebServer db:PostgreSQL instance:Redis } net:DMZ { server:WAF server:ReverseProxy } domain:Platform { subdomain:Identity { app:Auth_Service } subdomain:API { server:API_Gateway } }
Hybrid mode — env + domain on the same entities

Entities in both an env: block and a domain: block stay inside the env subgraph spatially, but their fill colour changes to the domain's palette colour — showing deployment topology and ownership simultaneously.

env:Production { app:PaymentService // stays inside Production subgraph app:AuthService } domain:Finance { app:PaymentService // tints node with Finance colour (fuchsia) }

Semantic Linting
Warnings appear beside the preview status and as wavy underlines in Smart Input. Click the warning pill to review issues, then click an issue to jump to its source line.
WarningWhat it catches
ORPHAN_NODEAn entity is declared but not connected by any relationship.
DUPLICATE_LABELThe same label appears under different entity types, such as app:User and db:User.
UNKNOWN_PREFIXA prefix is not one of Meridian's supported entity types.
INVALID_ARROWArrow-like text does not match supported syntax like A --> B or A --label--> B.
EMPTY_GROUPAn env:, net:, domain:, or subdomain: block has no valid child entities.
RELATIONSHIP_TO_CONTAINERA relationship targets an env:, net:, domain:, or subdomain: container instead of a concrete node inside it.
Toolbar & Pickers
The toolbar above the Smart Input gives quick access to entity insertion, templates, cloud service icons, and app settings.
🏷️ Entities ▾

Opens a grid of all 13 entity types, each shown as a colour-coded badge pill with a short description. Click any card to insert that prefix at the cursor — the diagram updates live as you type the entity name after it.

⚙️ Appearance settings

Opens the Appearance panel with two tabs.

TabSettings
Editor Theme — 6 colour presets: Meridian, One Dark, Dracula, Nord, Monokai, Solarized.
Font size — 11 / 13 / 15 / 17 px.
Font family — System mono, Fira Code, Cascadia Code, JetBrains Mono.
Token colours — individual colour pickers for every entity type prefix (env:, app:, db: …). Switching theme resets overrides to the new theme's defaults.
Diagram Font size — slider 10–28 px (enable checkbox to activate).
Node fill / border — primary fill and border colours.
Edge color — arrow and connector line colour.
Edge motion — off, slow, or fast moving-arrow overlay that leaves the generated Mermaid code unchanged. Works across all diagram types, including edges between nodes inside domain: and subdomain: grouping blocks.
Background — canvas background colour.
Custom diagram colours work best with the 🎨 Base diagram theme.

All settings are saved to localStorage automatically. Reset all restores every setting to its default value.

🌙 / ☀️ Theme toggle

Switches the app between dark and light themes. The preference is saved to localStorage and restored on next open.
